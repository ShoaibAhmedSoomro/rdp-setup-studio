    Your own Windows computer in the cloud

    By the end of this guide you'll open a full Windows computer in a window on your PC. It runs on GitHub's servers, only you can reach it, and it's free. You set it up once, then start it whenever you need it, for up to 6 hours at a time.

    Three free tools make it work

    • GitHubBuilds the cloud computer for you each time you ask.
    • TailscaleA private connection between your PC and the cloud computer.
    • Remote DesktopAlready on your Windows PC. It shows the cloud computer in a window.
    You won't type any passwords here.This page only gives directions. Anything private goes straight into GitHub or Tailscale.

    Tick each one to continueDon't have an account yet? The links open the free sign-up page.

    One word, like your first name. No spaces.

    On GitHub

    Create your project on GitHub

    This is the folder on GitHub where your setup lives. You only do this once.

    Open GitHub
    1. Click the black Open GitHub button above.GitHub opens in a new tab called "Create a new repository".
    2. Look at the Repository name box. It already says .If a red message says the name already exists, you made it before. Tick the box below and continue.
    3. A little lower, find the two round options and click .Under the description box
    4. Leave every other option as it is. Don’t tick "Add a README file".
    5. Scroll to the bottom and click the green Create repository button.Bottom right of the page
    6. A page titled "Quick setup" appears. That means it worked. Come back to this tab.
    Your project will be visible to everyone.Anyone could see the password GitHub shows. Choosing "Only me" in step 2 is safer.

    Tick when you see this

    Already made this project before?

    That's fine. Tick the box and continue.

    On GitHub

    Add the setup file

    This file tells GitHub how to build your Windows computer. We've written it for you from your details.

    Open the file in GitHub
    1. Click the black Open the file in GitHub button above.GitHub opens its file editor in a new tab.
    2. At the top, check the name box reads .github/workflows/rdp.yml.Top left, next to your project name
    3. Below it, the big white area is already full of text that starts with name:. Don’t change anything.
    4. Click the green Commit changes... button.Top right of the page
    5. A small window called "Commit changes" opens. Leave everything as it is and click the green Commit changes button inside it.Bottom right of the small window
    6. Click Actions in the row of tabs at the top of your project.Top of the page, between "Pull requests" and "Projects"
    7. If you see a green I understand my workflows, go ahead and enable them button, click it.Most people won’t see this. That’s fine.
    8. On the left you’ll now see . Come back to this tab.
    The editor opened empty?

    Click Copy the file below, click inside the big empty box on GitHub, and press Ctrl+V to paste. Then type .github/workflows/rdp.yml in the name box at the top.

    On Tailscale
    
          
    Get a key from Tailscale
    
        
    The key is like an invitation. It lets your cloud computer join your private connection, so your PC can reach it and no one else can.
    
        
    Open Tailscale
    
        
      
          
    1. Click the black Open Tailscale button above.If Tailscale asks you to sign in, choose the same way you signed up, for example "Sign in with GitHub".
      2. 
          
    2. You land on the "Keys" page. Find the "Auth keys" section and click Generate auth key...Middle of the page, on the right of "Auth keys"
      3. 
          
    3. A window called "Generate auth key" opens. Click the Description box and type GitHub RDP.
      4. 
          
    4. Click the Reusable switch so it turns on.A switch is on when it fills in and the dot moves to the right.
      5. 
          
    5. Under Expiration, choose 90 days.
      6. 
          
    6. Click the Ephemeral switch so it turns on too.
      7. 
          
    7. Leave "Tags" and "Pre-approved" switched off.
      8. 
          
    8. Click Generate key.Bottom right of the window
      9. 
          
    9. The key appears. Click Copy next to it.Don’t close this window yet. You’ll paste the key in the next step.
      10. 
        
    
        
    Keep this key private, like a password.Only paste it into GitHub in the next step. Never send it in a message or email.

      4.

    Something not working?
    
        
    "Remote Desktop can't connect to the remote computer"
          
    Click the Tailscale icon near the clock and check it says Connected, with the same account as the key. Then check the GitHub run is still running (yellow spinning circle). If it finished, start a new one from step 8.
    
        
    "The credentials that were used to connect did not work"
          
    Type the user name with the dot and backslash first: .\. Copy the password from the newest run's Summary page, not an older one.
    
        
    A step on GitHub shows a red cross
          
    If it's "Connect to Tailscale network", the key is wrong or expired. Make a new one (step 5) and save it again (step 6). If it's "Create user account", your own password was too simple. Change it in step 6.
    
        
    I can't find "Run workflow"
          
    Open your project's Actions tab. If there's a green button about enabling workflows, click it. Then click  on the left.
